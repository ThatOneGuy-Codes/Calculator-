This is my virtual calculator, designed with simple usability as well as offering a wide variety of mathematical options.

The newest version is now V 1.0.3 which features:
  - Number Checking
  - Fixed bug when entering exponent mode
  - Text Dividers

This update now checks if the inputs given are valid number inputs
and also includes new text dividers to make the output look cleaner.

A bug when entering exponent mode which caused it not to work has also
been fixed.

The operations for this version V 1.0.3 include:
  - Addition
  - Subtraction
  - Multiplication
  - Division
  - Exponent/Power Of
  - Square Root

With many more updates to come! Watch this repo for updates!
